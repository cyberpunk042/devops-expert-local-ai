# Project Management — Retrospective

Analyze recent work and extract lessons.

## Process

1. Review recent git history, completed milestones, task history
2. Identify: what went well, what went poorly, what was surprising
3. Categorize: keep doing / stop doing / start doing
4. Generate specific action items with owners
5. Update project state with retrospective findings
